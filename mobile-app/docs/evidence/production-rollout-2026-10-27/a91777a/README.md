# Verified first rollout / historical checkpoint

This directory records the first successful a91777a backend activation and APK4 publication. The later legacy-support compatibility candidate is recorded separately; do not attribute its result to this image. All JSON reports are sanitized (no credentials, tokens, customer record contents or private environment values). The archive identity record proves both classic config and containerd manifest identities rather than trusting a surprise host image ID.

`first-attempt-*` files are unsuccessful/exploratory historical checks made after automatic image rollback. They are not accepted runtime evidence. The HTTP harness then used unsupported `week/month/year` periods; the final accepted check uses the actual app/API `this_week/this_month/this_year` values. The final reports without that prefix record actual successful checks against the reviewed live backend. Native device and real push acceptance remain separate.
