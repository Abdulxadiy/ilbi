# P02f — shared web/desktop adjustment protocol and atomic journal foundation

The shared renderer now has a strict decimal/quote/acknowledgement codec for the same actual isolated API fixture consumed by native. It checks source actor/store/customer/branch, action/channel/reason, selected-currency arithmetic and credit bounds, original key/quote token, signed payment and no implicit FX. It strips opaque response fields and formats exact integer cents. This slice does not yet replace the existing refund form or call the new API.

The browser journal uses real IndexedDB readwrite transactions across independent connections. It persists the original operation/customer/body/key before a future write, admits one pending refund per source/account/store, preserves confirmed immutable operation results, keeps rejected history and clears a lock only after a checked acknowledgement or explicit fresh rejection. Unavailable storage aborts preparation; there is no in-memory/localStorage fallback that could permit an unjournaled financial write. Source and canonical stored payload are revalidated on read, and corruption is reported while preserving the original record.
